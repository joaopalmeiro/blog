# blog

My personal blog.

Install [fnm](https://github.com/Schniz/fnm) (if necessary).

```bash
fnm install && fnm use && node --version && npm --version
```

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run format
```

## Deployment

```bash
npm run build
```

```bash
npm run deploy
```
